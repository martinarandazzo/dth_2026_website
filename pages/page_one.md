## What are the advantages of open source software?

### 1. Creative freedom and collaboration

Open source software lets you see the code and fork it, which means to create a copy, and gives you the opportunity to make something new or improved that serves in your context freely, as long as you respect what its license states.
You do not need to be tech-savvy to start working on your ideas for an open source software, for example you might start a repository on Github and find like-minded skilled people that would look forward to contributing to your project.
The communities of contributors and supporters that surround open source software might also offer a variety of approaches and points of view that could benefit and improve projects.
One could possibly find more variety to satisfy their current needs rather than with what most mainstream closed-source would offer.

### 2. Community problem solving and continuous improvement
Access to the source code makes it easier to spot bugs and identify areas that can be improved. Because anyone can inspect the source code and propose fixes, open source projects benefit from continuous, worldwide collaboration. Instead of waiting for a single company to release an update, a diverse community of users and developers constantly refines these open source software tools from which thousands of people and their work benefit, ensuring that the projects keep evolving towards their best version.

### 3. Accessibility
Access to these free software makes it easier for people to start learning how to use technology when they are at the very first ropes with it and/or are not sure if they could or would pay for more advanced/famous closed-source programs.
For example, I started learning how to use a computer a little after having learnt how to read and write and my father would teach me how to type and transcribe text from my books at primary school through OpenOffice, which has now been succeeded by LibreOffice.
This also helps public institutions, such as a municipality with a limited budget, provide digital tools to citizens and staff without paying expensive licensing fees. On a larger scale even bigger public institutions like the Italian Ministry of Defense have migrated to open source software such as LibreOffice to save millions of euros in licensing fees and keep public documents independent from proprietary software.

### 4. Longevity and independence
Unlike proprietary software that can be discontinued overnight, open source projects do not have to die when their creators move on. As a matter of fact, because the source code is publicly available, anyone can fork and improve an abandoned project, giving it a second life and ensuring that students, researchers or anyone that could benefit from its usage can keep using the tool, just like LibreOffice did when it forked and succeeded OpenOffice.
